# vci-2026

2026 年可视计算与交互概论课程 Lab1、Lab2 提交材料。

## 实验材料

| 实验 | 源代码 | 实验报告 | 原始提交包 |
| --- | --- | --- | --- |
| Lab1 | [tasks.cpp](lab1/tasks.cpp) | [LAB1实验报告.pdf](lab1/LAB1实验报告.pdf) | [lab1.zip](submissions/lab1.zip) |
| Lab2：几何处理 | [tasks.cpp](lab2/tasks.cpp) | [lab2实验报告.pdf](lab2/lab2实验报告.pdf) | [lab2.zip](submissions/lab2.zip) |

Lab2 包含 Loop 网格细分、弹簧质点参数化、网格简化、Laplacian 网格平滑和 Marching Cubes。

## 使用说明

本仓库保存提交代码和报告；运行实验需要使用课程提供的 [VCI 2026 框架](https://gitee.com/pku-vcl/vci-2026/)，将相应实验的 `tasks.cpp` 放回框架对应目录后编译运行。

`lab1/`、`lab2/` 中的文件均从对应的提交压缩包原样提取。`submissions/` 保存原始 ZIP 文件。文件来源和 SHA-256 校验值记录在 [SUBMISSION_MANIFEST.json](SUBMISSION_MANIFEST.json) 中。
